# BRTK (BedRockToolKit)

BRTK is meant to be a installation, recovery and portable toolkit meant to be on a single USB. To aleviate the potential problems of a multi-iso solution such as ventoy. This is a solution that is a single ISO and will be able to install multiple distros such as Debian, Fedora, Arch, Alpine, and any source distribution that may be nessacary.

This is in VERY VERY early stages, and may take a long time to be completed. 

Current resources used is the SystemRescue tool list (https://www.system-rescue.org/Detailed-packages-list/) the LinuxFromScratch prereq list (https://www.linuxfromscratch.org/lfs/view/stable-systemd/chapter02/hostreqs.html) and other sources that will be cited upon the first release.
